# NHAI Hackathon - LuminaTrack

LuminaTrack is a high-quality React-based web application tailored for the NHAI Hackathon. The platform operates completely in the browser, offering a sophisticated dark mode aesthetic and a functional frontend computer-vision analyzer for Retro-Reflectivity Measurement.

## Features
- **Dashboard Overview**: KPI metrics for compliance rates and average reflectivity.
- **Image Analyzer**: Frontend Computer Vision using HTML5 Canvas to calculate pixel luminance.
- **PDF Reporting**: Instantly generate and download reports using jsPDF.

## Development Setup

```bash
npm install
npm run dev
```
